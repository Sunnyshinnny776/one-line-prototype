## 简体中文

- 第一个版本。给一句话需求，问一轮会改变产品的规则，产出精简 PRD、流程图、可交互原型和确认单。
- 原型是单个 HTML 文件，断网能打开，规则通过灯泡对回 PRD 的编号。
- 确认单只给你本人看，列出 skill 自己补的内容和没确认的问题。
- 需求过大时，引导你改用 PM Agentic Cookbook 的完整流程。

## English

- First release: turns a one-line requirement into a concise PRD, flow diagrams, an offline clickable prototype and a confirmation sheet.
