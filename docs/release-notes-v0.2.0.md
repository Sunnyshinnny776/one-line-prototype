- skill 补的规则如果会收窄你的需求，不再直接补，先问你。

- 反馈说明结构理解错了时，整体重做，不在原页面上打补丁。
- 原型页面更简洁：说明收进提示图标，规则编号在灯泡里；批量操作按每条记录设计。
- 有界面参考时，确认单的配色跟原型一致。
- 修复规则灯泡在网格或会换行的容器里多出一行的问题。
- skill 目录里加了 LICENSE.txt 和 NOTICE.txt。
